# Do agent skills actually help?

Agent skills are packaged procedural knowledge that a model loads at inference time. Adoption has been fast, but until recently [@mizuta1968] there was no standard way to measure whether a skill improves anything.[@hayashi2003]

The first benchmark to pair tasks with [@li2026skillsbench] curated skills and deterministic verifiers reports a sizeable gain in pass rate when skills are present, and finds that small, focused skill bundles beat exhaustive ones [@li2026skillsbench]

That result is the one to cite in the introduction.
