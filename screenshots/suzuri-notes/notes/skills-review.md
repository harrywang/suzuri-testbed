# Do agent skills actually help?

Agent skills are packaged procedural knowledge that a model loads at inference time. Adoption has been fast, but until recently there was no standard way to measure whether a skill improves anything.

The first benchmark to pair tasks with curated skills and deterministic verifiers reports a sizeable gain in pass rate when skills are present, and finds that small, focused bundles beat exhaustive ones [@li2026skillsbench].
